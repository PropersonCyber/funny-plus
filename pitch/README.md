## 改的时候注意

- 配色沿用 `docs/materials/tokens/design-tokens.json`，改色只动 `:root`。
- 新增页面：复制一个 `<section id="sX">` + 在 `<nav id="nav">` 加一个点，`#bar` 与高亮会自动生效。
- 入场动画依赖 `.js` 类，无 JS 环境下内容默认可见（不会白屏）。
- 图片全部用相对路径 `assets/`，不要引外链。
