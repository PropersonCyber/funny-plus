# Funny+ 投资介绍书

打开 `index.html` 查看当前版本。页面无构建步骤，图片均使用 `assets/` 中的项目素材与模拟器截图；浏览器打印可导出 PDF。

内容包含用户问题与访谈场景、产品截图、技术方法、市场与竞争格局、商业假设、进展、风险以及融资信息。竞品补充一节用两张能力对照表覆盖 11 个产品——行程规划类 6 家（圆周旅迹、指北旅行、Gooh旅记、小旅星、随鹿旅行、十六番）与平台类 5 家（小红书、马蜂窝、携程 Trip.Planner、飞猪、高德地图）——与 Funny+ 逐行对照，标注每格依据（● 明确具备 / ◐ 部分 / ○ 未见公开说明），并写明我们落后的项。资料与口径见页面底部，收入演算为待验证假设。

对外发送前，请复核产品及数据口径，并补充团队背景、真实运营数据、融资金额、资金用途、里程碑和联系方式。截图中的评分、人次为展示文案，预算为示例估算。
